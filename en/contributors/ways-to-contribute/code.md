# Contribute to code

Stride is an open source project, meaning that anyone can view and contribute to it's code. The source code is hosted on GitHub

## How to start contributing

It's important to keep in mind when suggesting changes that Stride is a community project, meaning that modifying crucial components to your liking may be unwanted by others.

When starting out, make sure to **familiarize yourself with the architecture**. The best way to do that is to first try tackling issues labeled [good first issue](https://github.com/stride3d/stride/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22good%20first%20issue%22).
