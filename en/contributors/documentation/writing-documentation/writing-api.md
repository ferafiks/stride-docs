# Writing API

The API documentation is generated from Stride's source code, meaning that if you want to edit it, you will have to do so on the [engine repository](https://github.com/stride3d/stride).

## Edit API documentation

1. Fork the [engine's source code](https://github.com/stride3d/stride).
2. Either clone your repository to your computer or use GitHub for editing.
3. Find the script that you want to edit.
4. Modify the API (text that is preceded by `///`).
