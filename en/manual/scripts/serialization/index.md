# Serialization

<span class="badge text-bg-primary">Beginner</span>
<span class="badge text-bg-success">Programmer</span>

Scripts that are attached to entities can expose certain properties and fields for serialization. They can be modified via the **Property grid** panel.

## Rule of thumb

If the property or field is accessible outside of a script from code, it will be accessible from the **Property grid** with a few exceptions.

For more information about how properties and fields are serialized, visit the [properties and fields page](properties-and-fields.md).
